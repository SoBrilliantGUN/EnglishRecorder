# EnglishPod 学习打卡

一个专为 EnglishPod 学习者设计的打卡记录工具，帮助你追踪每节课的学习进度，并根据艾宾浩斯遗忘曲线自动提醒复习时间，让记忆更牢固。

数据全部存储在本地浏览器中，无需注册、无需后端。（AI说Recorder听起来像录音机，所以应该叫English Tracker才对）

## 功能

**打卡日历**
- 月视图日历，周一起始
- 点击任意历史日期，右侧卡片实时显示该日的学习内容
- 有打卡记录的日期显示圆点标记

**当日学习内容**
- 右侧侧边栏顶部，默认显示今天的学习内容
- 点击日历日期后切换为所选日期
- 展示该日各课程编号及学习次数
- 内含"打卡"按钮，点击弹窗录入当日记录

**学习记录**
- 按日 / 按周 / 按月三种维度查看
- 按日视图支持删除单日课程记录
- 底部显示打卡次数、总学习遍数、涉及课程数汇总
- 支持导出 JSON 备份 / 导入恢复数据
- 可将当前视图记录截图保存为 PNG 分享

**复习提醒**
- 基于艾宾浩斯间隔（1、2、4、7、15、30、60 天）计算每门课的下一次复习日期
- 复习进度动态计算，补录历史数据后自动调整：
  - 以该课**最早打卡日期**为起点
  - 有记录的**不同日期数 - 1**即为已完成复习轮次（同一天多条记录只算一次）
  - 下次复习日：若理论日期未到则使用理论日期；若已过期且今天已有记录则顺延至明天，否则为今天
- 仅展示近 3 天内需要复习的课程，超过 3 条可展开查看
- 支持单课程重置复习起点
- 点击右上角 ⚙ 图标展开复习设置：全局遗忘曲线系数（0.5 ～ 3.0）调整及 7 次复习日期预览

## 技术栈

- React + Vite
- html2canvas
- localStorage
