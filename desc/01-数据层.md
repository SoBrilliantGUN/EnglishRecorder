# 任务01：数据层

## 实现位置
`app/src/store.ts`

## 目标
封装所有 localStorage 读写操作，提供统一的数据访问接口和工具函数。

## 初始化逻辑
- 页面加载时检查 `ep_initialized` 标志
- 若不存在，插入2条示例记录（当天日期，课程1听了1次，课程2听了2次），并设置 `ep_initialized = true`
- 同时初始化 `ep_first`：课程1和课程2的首次学习日期均为今天

## 数据读写接口

### 记录相关
```typescript
getRecords(): Record[]
saveRecords(records: Record[]): void
addRecord(lesson: number, count: number, date: string): void
deleteRecordsByDateAndLesson(date: string, lesson: number): void
// 若删完后该课程无记录，内部自动调用 clearFirstDate + clearReset
```

### 课程首次学习日期
```typescript
getFirstDates(): { [key: string]: string }
setFirstDate(lesson: number, date: string): void
clearFirstDate(lesson: number): void
```

### 重置状态
```typescript
getResets(): { [key: string]: string }
setReset(lesson: number, date: string): void
clearReset(lesson: number): void
```

### 系数
```typescript
getCoef(): number           // 默认 1.0
setCoef(value: number): number  // clamp 到 [0.5, 3.0]，返回实际存储值
```

### 导入导出
```typescript
exportData(): void    // 触发下载，文件名：englishpod-backup-YYYY-MM-DD.json
importData(jsonObj: ImportData): void  // 完整替换 ep_records/ep_coef/ep_first/ep_resets
```

### 统计聚合
```typescript
getStats(records: Record[]): Stats
// → { checkins: 原始记录条数, total: count 之和, lessons: 去重课程数 }

groupByLesson(records: Record[]): [string, number][]
// → 按课程编号升序排列的 [lessonId, totalCount] 数组
```

## 记录ID生成规则
```typescript
id = `${Date.now()}-${Math.random().toString(36).slice(2, 7)}`
```

## 注意事项
- 课程编号统一存为数字类型
- 所有日期格式统一为 `YYYY-MM-DD`
