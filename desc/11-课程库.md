# EnglishPod 课程库

## 功能概述

在打卡日历卡片下方展示 EnglishPod 课程列表卡片，点击某课进入详情视图。

## 数据来源

课文数据预先从 PDF 解析为 `src/data/podcasts.json` 静态 JSON 文件，构建时打包。共 365 课（ID 1-365），每课包含：
- `id`：课程编号（1-365）
- `code`：原始编码（如 B0001、C0320）
- `level`：难度级别（Elementary / Intermediate / Upper-Intermediate / Advanced）
- `title`：课程标题
- `content`：对话文本，格式为每行 `说话人: 台词`，行间以 `\n` 分隔（331-365 课为空字符串占位）

节目文字稿数据存放在 `public/transcripts/` 目录，共 365 个 JSON 文件（`englishpod_0001.json` ~ `englishpod_0365.json`），每文件结构为：
```json
{ "transcript": "完整节目文字稿..." }
```
文字稿在课程详情页按需 fetch 加载，不参与构建打包。

## 组件结构

### PodcastList（课程列表卡片）

位置：打卡日历下方，同一左侧主区域内。

功能：
- 搜索：按标题或编号筛选
- 级别筛选：药丸按钮，带颜色圆点标识
- 响应式网格：`repeat(auto-fill, minmax(200px, 1fr))`，卡片数量随宽度变化
- 分页：默认每页 20 课，可通过下拉选择 10/20/50/100 条/页，传统页码导航（带省略号）
- 页码状态提升到 App.tsx，从详情返回列表时页码保持不变
- 卡片样式：左侧色条标识级别，hover 时边框变色 + 微上移 + 阴影

### PodcastDetail（课程详情）

位置：替代 PodcastList 显示在同一区域，点击返回按钮回到列表。

功能：
- 顶部导航：返回按钮 + 课程编号与级别标签（居中）+ 操作按钮区
  - **单课打卡**（btn-primary）：点击弹出 CheckinModal，课程编号锁定为当前课，打卡成功后自动弹出单课分享弹窗（ShareModal single 模式）
  - **分享**（btn-secondary）：仅当今天已有该课的打卡记录时显示，点击再次打开 ShareModal single 模式
  - 上一课/下一课按钮在第 1 课或最后一课时对应方向置灰禁用
  - 切换课程通过 `onNavigate(id)` 回调更新 App.tsx 的 `selectedLessonId`
- 对话文本展示：带滚动、自定义滚动条（content 为空时该区块不渲染）
- 节目文字稿展示：进入详情页时 fetch `/transcripts/englishpod_XXXX.json`，加载完成后渲染在对话文本下方；加载中显示"加载中..."，fetch 失败显示"暂无文字稿"
- 对话格式：每行 `说话人: 台词`，说话人可以是单字母（A/B/C/D）、全大写缩写（SONG）或真实姓名（Sarah、Tom 等）

## 类型定义（types/podcast.ts）

```typescript
interface Podcast { id, code, level, title, content }
```

## 级别颜色映射

| 级别 | 颜色变量 |
|------|----------|
| Elementary | `--color-success` (#27ae60) |
| Intermediate | `--color-info` (#3498db) |
| Upper-Intermediate | `--color-warning` (#F59E0B) |
| Advanced | `--color-danger` (#e74c3c) |

## 视图切换逻辑

App.tsx 中通过 `selectedLessonId` 状态控制：
- `selectedLessonId === null`：显示 PodcastList
- `selectedLessonId !== null`：显示 PodcastDetail，同时传入 `onNavigate={setSelectedLessonId}` 供课程间切换

不引入新的 `view` 状态值，Podcast 功能始终在 `view === 'calendar'` 时显示在日历下方。
