# EnglishPod 课程库

## 功能概述

在打卡日历卡片下方展示 EnglishPod 课程列表卡片，点击某课进入详情视图。

## 数据来源

课程数据唯一源为 `public/transcripts/` 目录下的 365 个 JSON 文件（`englishpod_0001.json` ~ `englishpod_0365.json`），每文件包含完整信息：

```json
{
  "code": "B0001",
  "title": "Difficult Customer",
  "transcript": [{ "en": "...", "zh": "..." }],
  "dialogue": [{ "en": "A: ...", "zh": "A：..." }]
}
```

- `transcript`：节目完整文字稿（`TransSegment[]`），ID 1-9, 22-24 人工校对；ID 10-21, 25-50 翻译完成；其余未翻译
- `dialogue`：课文对话内容（`TransSegment[]`，含说话人标签 A:/B:/C:），ID 1-50 已翻译
- `code` / `title`：课程元数据（级别从 code 前缀推导：A/B=Elementary，C=Intermediate，D=Upper-Intermediate，E/F=Advanced）

构建时从 transcript 文件提取元数据生成 `src/data/podcasts-index.ts`（仅含 `id/code/title/level`，约 42KB），供列表和分享组件使用。详情页按需 `fetch('/transcripts/englishpod_XXXX.json')` 加载完整文字稿和课文对话，不参与构建打包。

## 组件结构

### PodcastList（课程列表卡片）

位置：打卡日历下方，同一左侧主区域内。

功能：
- 搜索：按标题或编号筛选
- 级别筛选：药丸按钮，带颜色圆点标识
- 响应式网格：`repeat(auto-fill, minmax(200px, 1fr))`，卡片数量随宽度变化
- 分页：使用 `Pagination` 统一分页组件（`variant="full"`），默认每页 20 课，可通过下拉选择 10/20/50/100 条/页，页数多时自动折叠省略号
- 页码状态提升到 App.tsx，从详情返回列表时页码保持不变
- 卡片样式：左侧色条标识级别，hover 时边框变色 + 微上移 + 阴影

### PodcastDetail（课程详情）

位置：替代 PodcastList 显示在同一区域，点击返回按钮回到列表。

功能：
- 顶部导航：返回按钮 + 课程编号与级别标签（居中）+ 操作按钮区
  - **单课打卡**（btn-primary）：点击弹出 CheckinModal，课程编号锁定为当前课，打卡成功后自动弹出单课分享弹窗（ShareModal single 模式）
  - **分享**（btn-secondary）：仅当今天已有该课的打卡记录时显示，点击再次打开 ShareModal single 模式
  - 上一课/下一课按钮在第 1 课或最后一课时对应方向置灰禁用
  - 切换课程通过 `onNavigate(id)` 回调更新 App.tsx 的 `selectedLessonId`
- 对话文本展示：带滚动、自定义滚动条（content 为空时该区块不渲染）；支持结构化 `TransSegment[]` 格式，每轮对话独立渲染，英文下方可显示中文翻译
- 翻译模式切换：顶部导航栏有"译"按钮，切换两种显示方式：
  - 完全显示：中文翻译始终显示在对应英文行下方
  - 悬浮显示：中文翻译默认隐藏（仍占位），鼠标悬停到英文行时显示
- 课文对话 + 节目文字稿展示：进入详情页时 fetch `/transcripts/englishpod_XXXX.json`，同时获取 `dialogue`（课文对话）和 `transcript`（节目文字稿）；加载中显示"加载中..."，fetch 失败显示"暂无文字稿"；均支持结构化翻译格式和翻译模式切换
- 对话格式：每行 `说话人: 台词`，说话人可以是单字母（A/B/C/D）、全大写缩写（SONG）或真实姓名（Sarah、Tom 等）
- **自动滚动 + 回顶部**：由 `AutoScroll` 组件统一管理。
  - 桌面端（≥769px）：右侧悬浮胶囊，紧凑态为圆形播放按钮，点击即开始自动滚动并展开为横向胶囊（播放/暂停 + 速度设置⚙ + 回顶部↑ + 快捷键提示⌨ + 关闭✕）。回顶部按钮 scrollY > 200 时淡入。
  - 移动端（≤768px）：底部控制条始终可见（回顶部 + 播放 + 速度设置），无关闭按钮避免关闭后无法重新打开。
  - 速度 8 级（60~120 px/s），通过 ± 按钮或键盘 ↑↓ / + − 调节，持久化到 `ep_auto_scroll_speed`。
  - 键盘快捷键：← → 切换课程、Space 暂停/继续、↑↓/+− 调速、Esc 退出。首次使用自动弹出提示。
  - 手动滚动自动暂停，到达底部自动停止。回顶部点击立即停止滚动。

## 类型定义（types/podcast.ts）

```typescript
interface PodcastMeta {
  id: number; code: string; title: string; level: string;
  isProofread: boolean;               // 是否人工校对
  hasDialogueTranslation: boolean;     // 课文对话是否有中文翻译
  hasTranscriptTranslation: boolean;   // 节目文字稿是否有中文翻译
}
interface Podcast extends PodcastMeta { content }          // 含按需加载的对话
```

## 角标图例

课程卡片右上角显示翻译/校对状态角标：

| 角标 | 颜色 | 含义 |
|------|------|------|
| **校** | 蓝色 | 人工校对完成（`isProofread`） |
| **译** | 绿色 | 含中文翻译（`hasDialogueTranslation` 或 `hasTranscriptTranslation`） |

卡片优先显示蓝色"校"角标；非校对课程若有课文对话或文字稿任一翻译，则显示绿色"译"角标。两者均无则不显示。

| Elementary | `--color-success` (#27ae60) |

## 视图切换逻辑

App.tsx 中通过 `selectedLessonId` 状态控制：
- `selectedLessonId === null`：显示 PodcastList
- `selectedLessonId !== null`：显示 PodcastDetail，同时传入 `onNavigate={setSelectedLessonId}` 供课程间切换

不引入新的 `view` 状态值，Podcast 功能始终在 `view === 'calendar'` 时显示在日历下方。

### 翻译流程
```
split-sentences.mjs（逐句拆分）
  → split-sentences.mjs --split-long（长句 >55 字符二次拆分，按自然断点）
  → rebalance-transcripts.mjs（批量重拆分全部文件至 ≤55 字符，同步拆分 zh 字段）
  → 人工/并行 EN→ZH 翻译
  → apply-translations.mjs（课文翻译写入）
  → apply-transcript-translations.mjs（文字稿翻译写入）
  → build-index.mjs（重建课程索引，更新角标）
```

**重要规则**：校对完课文后，必须同步对齐对应文字稿中的3遍对话的英文和中文，使其与课文严格一致（文字稿中对话录音共播放3遍）。
