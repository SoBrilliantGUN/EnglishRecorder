## 全局状态（useState）
```typescript
const [view, setView] = useState('calendar');          // 'calendar' | 'records'

const [showProfile, setShowProfile] = useState(false); // 个人中心弹窗
const [privacyConsented, setPrivacyConsentedState] = useState(() => hasPrivacyConsent()); // 隐私政策同意状态

```

## 刷新机制
```typescript
const refresh = () => setTick(t => t + 1);
```
`tick` 作为 prop 传入 `Calendar`、`DailyCard`、`ReviewReminder`，记录变动后调用 `refresh()` 即可触发全量重渲染。

## 启动流程（三级准入）
1. **隐私同意**：`!privacyConsented` → 渲染 `<PrivacyConsent>`，不同意则显示退出页
2. **登录**：`privacyConsented && !user` → 渲染 `<LoginPage>`
3. **主界面**：`privacyConsented && user` → 渲染完整应用（Header + 内容 + Footer）
- 登录成功后 `setUser(profile)` 切换到主界面
- 退出登录时 `setUser(null)` 并重置 `selectedLessonId`、`podcastPage`
- LoginPage 和 PrivacyConsent 内部管理子视图（登录表单 / 隐私政策 / 用户协议），点击协议链接时切换

## 布局
- 左侧：`flex: 1 1 0; minWidth: 0`，纵向堆叠 Calendar/RecordsView + PodcastList/PodcastDetail
- 右侧：`flex: 0 0 350px; alignSelf: flex-start`，DailyCard + ReviewReminder（可隐藏）
- Header 右侧图标栏新增用户头像按钮，点击打开个人中心弹窗

## 调用时机
- 打卡成功后
- 删除记录后
- 重置复习计划后
- 系数变更后
- 导入数据后
