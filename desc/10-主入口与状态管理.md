# 任务10：主入口与状态管理

## 实现位置
`app/src/App.tsx`

## 目标
实现页面初始化和全局状态管理。

## 初始化
```typescript
useEffect(() => { initData(); }, []);
```

## 全局状态（useState）
```typescript
const [view, setView] = useState('calendar');  // 'calendar' | 'records'
const [tick, setTick] = useState(0);           // 变化时驱动子组件重渲染
const [selected, setSelected] = useState(todayStr()); // 当前选中日期
const [showInfo, setShowInfo] = useState(false);      // 使用说明弹窗
const [showSettings, setShowSettings] = useState(false); // 设置弹窗
const [showReview, setShowReview] = useState(() => localStorage.getItem('ep_show_review') !== 'false'); // 复习提醒显隐
const { theme, toggle: toggleTheme } = useTheme();   // 暗黑模式（来自 hooks/useTheme.ts）
```

## 刷新机制
```typescript
const refresh = () => setTick(t => t + 1);
```
`tick` 作为 prop 传入 `Calendar`、`DailyCard`、`ReviewReminder`，记录变动后调用 `refresh()` 即可触发全量重渲染。

## 调用时机
- 打卡成功后
- 删除记录后
- 重置复习计划后
- 系数变更后
- 导入数据后
