# 任务04：分享功能

## 实现位置
`app/src/components/ShareModal/`（独立目录）
- `index.tsx`：弹窗主体，主题切换 + PNG 复制/下载，支持 `mode: 'multi' | 'single'` 双模式
- `themes.ts`：`MULTI_THEMES` / `SINGLE_THEMES` 注册表
- `types.ts`：`MultiCardProps` / `SingleCardProps` / `MultiTheme` / `SingleTheme` 类型定义
- `components/`：各主题卡片组件，**均为单文件 `.tsx`**（如 `CardDark.tsx`），不使用目录结构，不引入 CSS Modules，所有样式内联——保证 html2canvas 导出正确

由 `RecordsView`、`DailyCard` 以 `mode='multi'`（或省略）调用；由 `PodcastDetail` 以 `mode='single'` 调用。

## 触发
1. **记录视图**：顶部"分享"按钮，分享当前 Tab（按日/周/月）数据
2. **学习内容卡片（DailyCard）**：打卡按钮旁的"分享"按钮，分享当前日期学习数据
3. **课程详情（PodcastDetail）**：单课打卡成功后自动弹出，分享单节课学习数据

## 主题选择
弹窗顶部提供两个主题切换按钮，`ep_share_theme` 持久化，多课与单课共享同一选择：

| 主题 ID | 显示名 | 多课组件 | 单课组件 |
|---------|--------|----------|----------|
| `dark` | 暗黑科技 | `CardDark.tsx` | `SingleCardDark.tsx` |
| `warm` | 清新活泼 | `CardWarm.tsx` | `SingleCardWarm.tsx` |

## 多课卡片内容
- 标题：时间标签（如"2026-06-03"或"2026年6月"）
- 统计区：打卡次数 / 学习次数 / 涉及课程数
- 课程明细：课程编号 + 次数列表
- 底部水印：EnglishPod Tracker

## 单课卡片内容
- 课程代码（如 B0023）+ 难度等级（带颜色）
- 课程标题（大字排版，主视觉焦点）
- 日期
- 本次学习次数 / 历史累计次数

## 复制图片
- 使用 `html2canvas`，`scale: 2` 保证清晰度
- `backgroundColor`：dark → `#0a0a0a`，warm → `#fff9f0`
- 优先 `navigator.clipboard.write` 复制到剪贴板，降级为下载 PNG

## 打卡弹窗（CheckinModal）
`app/src/components/CheckinModal/` — 从 DailyCard 抽出的公共打卡弹窗

```ts
interface CheckinModalProps {
  date?: string;          // 默认今天
  defaultLesson?: number; // 预填课程编号
  lockLesson?: boolean;   // true → disabled + 聚焦学习次数
  onClose: () => void;
  onSuccess?: (lesson: number, count: number) => void;
}
```

- `DailyCard` 不传 `defaultLesson`/`lockLesson`，聚焦课程编号输入
- `PodcastDetail` 传 `defaultLesson={lessonId}` + `lockLesson`，聚焦学习次数输入，打卡成功后自动弹出 ShareModal(single)
