# 任务04：分享功能

## 实现位置
`app/src/components/ShareModal/`（独立目录）
- `index.jsx`：弹窗主体，主题切换 + PNG 导出
- `themes.js`：`THEMES` 注册表，集中主题 id/显示名/组件的映射
- `components/`：各主题卡片组件（`CardDark` / `CardWarm` / `CardEditorial`），均为 default 导出

由 `RecordsView.jsx` 顶部"分享"按钮挂载，通过 `label` / `stats` / `groups` / `onClose` 四个 prop 通信。

## 目标
实现分享弹窗，支持三种主题卡片预览并下载为 PNG 图片。

## 触发
记录视图顶部的"分享"按钮。

## 主题选择
弹窗顶部提供三个主题切换按钮，用户选择后实时预览：

| 主题 ID | 显示名 | 组件文件 | 风格描述 |
|---------|--------|----------|----------|
| `dark` | 暗黑科技 | `components/CardDark.jsx` | 黑底 + 荧光绿 + 等宽字体 |
| `warm` | 清新活泼 | `components/CardWarm.jsx` | 暖橙渐变 + 圆角卡片 + 模糊光晕 |
| `editorial` | 杂志风 | `components/CardEditorial.jsx` | 深棕 + 金色 + 衬线字体 |

> 新增主题：在 `components/` 下加一个卡片组件文件，再到 `themes.js` 注册一行即可，`index.jsx` 无需改动。

## 卡片内容（三种主题均包含）
- 标题：当前视图时间标签（如"2026-06-03"或"2026年6月"）
- 统计区：打卡次数 / 学习遍数 / 涉及课程数
- 课程明细：课程编号 + 次数列表
- 底部水印：EnglishPod Tracker

## 下载
- 按钮文字："下载图片"
- 使用 `html2canvas` 截取卡片区域（`shareRef`），`scale: 2` 保证清晰度
- `backgroundColor` 根据当前主题设置（dark: `#0a0a0a`，warm: `#fff9f0`，editorial: `#1c1917`）
- 文件名：`englishpod-YYYY-MM-DD.png`（当前日期）

## 弹窗样式
- 白色圆角卡片，居中显示，有遮罩层（点击遮罩关闭）
- 最大宽度 420px

## 注意事项
- 分享内容根据当前 Tab（按日/周/月）和当前时段动态生成
- html2canvas 通过 npm 安装（非 CDN）
