# 任务04：分享功能

## 实现位置
`app/src/components/ShareModal/`（独立目录）
- `index.tsx`：弹窗主体，主题切换 + PNG 复制/下载
- `themes.ts`：`THEMES` 注册表，集中主题 id/显示名/组件的映射
- `types.ts`：`CardProps` / `Theme` 类型定义
- `components/`：各主题卡片组件（`CardDark` / `CardWarm` / `CardEditorial`），均为 default 导出

由 `RecordsView/index.tsx` 顶部"分享"按钮和 `DailyCard/index.tsx` 的"分享"按钮挂载，通过 `label` / `stats` / `groups` / `onClose` 四个 prop 通信。

## 目标
实现分享弹窗，支持三种主题卡片预览并复制为 PNG 图片到剪贴板。

## 触发
1. **记录视图**：顶部的"分享"按钮，分享当前 Tab（按日/周/月）和当前时段的数据
2. **学习内容卡片（DailyCard）**：打卡按钮旁的"分享"按钮，分享当前选中日期的学习数据（无记录时按钮禁用）

## 主题选择
弹窗顶部提供三个主题切换按钮，用户选择后实时预览：

| 主题 ID | 显示名 | 组件文件 | 风格描述 |
|---------|--------|----------|----------|
| `dark` | 暗黑科技 | `components/CardDark.tsx` | 黑底 + 荧光绿 + 等宽字体 |
| `warm` | 清新活泼 | `components/CardWarm.tsx` | 暖橙渐变 + 圆角卡片 + 模糊光晕 |
| `editorial` | 杂志风 | `components/CardEditorial.tsx` | 深棕 + 金色 + 衬线字体 |

> 新增主题：在 `components/` 下加一个卡片组件文件，再到 `themes.ts` 注册一行即可，`index.tsx` 无需改动。

### 主题偏好记忆
- 用户选择主题后，自动保存到 `localStorage`（key: `ep_share_theme`）
- 下次打开分享弹窗时，默认选中上次选择的主题
- 未保存过时默认为 `dark`

## 卡片内容（三种主题均包含）
- 标题：当前视图时间标签（如"2026-06-03"或"2026年6月"）
- 统计区：打卡次数 / 学习遍数 / 涉及课程数
- 课程明细：课程编号 + 次数列表
- 底部水印：EnglishPod Tracker

## 复制图片
- 按钮文字："复制图片"
- 使用 `html2canvas` 截取卡片区域（`shareRef`），`scale: 2` 保证清晰度
- `backgroundColor` 根据当前主题设置（dark: `#0a0a0a`，warm: `#fff9f0`，editorial: `#1c1917`）
- 通过 `navigator.clipboard.write` + `ClipboardItem` 将 PNG 写入剪贴板
- 复制成功后弹出提示
- **降级策略**：不支持 Clipboard API 时（如 HTTP 环境），自动 fallback 为下载图片，文件名：`englishpod-YYYY-MM-DD.png`

## 弹窗样式
- 白色圆角卡片，居中显示，有遮罩层（点击遮罩关闭）
- 最大宽度 420px

## 注意事项
- 分享内容根据当前 Tab（按日/周/月）和当前时段动态生成
- html2canvas 通过 npm 安装（非 CDN）
- DailyCard 的分享数据计算逻辑与 RecordsView 按日分享完全一致
