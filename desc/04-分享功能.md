# 任务04：分享功能

## 实现位置
`app/src/components/ShareModal/`（独立目录）
- `index.tsx`：弹窗主体，自动分流逻辑 + 主题切换 + PNG 复制/下载
- `themes.ts`：`MULTI_THEMES` / `TOPN_THEMES` / `SINGLE_THEMES` 注册表
- `types.ts`：`MultiCardProps` / `SingleCardProps` / `MultiTheme` / `SingleTheme` 类型定义
- `CLAUDE.md`：卡片设计规范，新增主题前必读
- `components/`：各主题卡片组件，**均为单文件 `.tsx`**，不使用目录结构，不引入 CSS Modules，所有样式内联——保证 html2canvas 导出正确

由 `RecordsView`、`DailyCard` 调用（传 `groups`）；由 `PodcastDetail` 以 `mode='single'` 调用。

## 触发
1. **记录视图（RecordsView）**：顶部左侧"分享"按钮，分享当前 Tab（按日/周/月）数据
2. **学习内容卡片（DailyCard）**：标题行"分享"按钮（有记录时才可点），分享当前日期学习数据
3. **课程详情（PodcastDetail）**：单课打卡成功后自动弹出，`mode='single'`；今天有记录时也显示"分享"按钮可手动触发

## 自动分流规则

`ShareModal` 根据 `groups.length` 自动选择卡片形态，调用方无需传 `mode`（单课打卡除外）：

| 课程数 | 展示形态 | 说明 |
|--------|----------|------|
| `mode='single'` | 单课卡片 | `PodcastDetail` 明确指定 |
| `groups.length = 1` | 单课卡片 | 自动转换，从 `podcasts.json` 补全课程信息 |
| `groups.length` 2～5 | 多课列表卡片 | 完整展示所有课程 |
| `groups.length > 5` | TopN 卡片 | 展示前 4 名 + 归并行（还学了 N 门，共 X 次） |

## 主题选择
弹窗顶部提供三个主题切换按钮，`ep_share_theme` 持久化，三种卡片形态共享同一主题选择：

| 主题 ID | 显示名 | 多课组件 | TopN 组件 | 单课组件 |
|---------|--------|----------|-----------|----------|
| `dark` | 暗黑科技 | `CardDark` | `CardDarkTopN` | `SingleCardDark` |
| `warm` | 清新活泼 | `CardWarm` | `CardWarmTopN` | `SingleCardWarm` |
| `cream` | 奶油纸本 | `CardCream` | `CardCreamTopN` | `SingleCardCream` |

## 多课卡片 Props（MultiCardProps）
```typescript
interface MultiCardProps {
  label: string;               // 时间标签，如 "2026-06-03" 或 "2026年6月"
  stats: {
    checkins: number;          // 打卡天数
    total: number;             // 学习总次数
    lessons: number;           // 课程数
  };
  groups: [string, number][]; // [lessonId字符串, 学习次数]，按课程ID升序
}
```

## 单课卡片内容
- 课程代码（如 B0023）+ 难度等级
- 课程标题（大字排版，主视觉焦点）
- 日期
- 本次学习次数 / 历史累计次数

## 复制图片
- 使用 `html2canvas`，`scale: 2` 保证清晰度
- `backgroundColor` 按主题：`dark → #08080f`，`warm → #f0faf6`，`cream → #faf6ef`
- 优先 `navigator.clipboard.write` 复制到剪贴板，降级为下载 PNG
- 文件名：`englishpod-{YYYY-MM-DD}.png`

## 打卡弹窗（CheckinModal）
`app/src/components/CheckinModal/` — 公共打卡弹窗

```typescript
interface CheckinModalProps {
  date?: string;          // 默认今天
  defaultLesson?: number; // 预填课程编号
  lockLesson?: boolean;   // true → 课程编号 disabled，聚焦学习次数
  onClose: () => void;
  onSuccess?: (lesson: number, count: number) => void;
}
```

- `DailyCard` 不传 `defaultLesson`/`lockLesson`，聚焦课程编号输入
- `PodcastDetail` 传 `defaultLesson={lessonId}` + `lockLesson`，聚焦学习次数输入，打卡成功后自动弹出 ShareModal(single)
