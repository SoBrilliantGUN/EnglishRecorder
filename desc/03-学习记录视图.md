# 任务03：学习记录视图

## 实现位置
`app/src/components/RecordsView/index.tsx`

## 目标
实现按日/按周/按月三种维度查看学习记录，支持时间导航、删除记录、数据汇总。

## 视图切换
- 在打卡日历页点击"查看记录"进入记录视图
- 记录视图顶部左侧有"打卡记录"标题，右侧有"返回打卡"按钮
- 三个 Tab：按日 / 按周 / 按月

## 时间导航
- 每个 Tab 下有左右箭头：
  - **按日**：前一天/后一天
  - **按周**：上一周/下一周
  - **按月**：上一月/下一月
- **不能查看未来**：右箭头最多到今天/本周/本月
- **切换 Tab 后始终重置到今天**

## 数据展示规则

### 按日
- 列出当天的所有打卡记录
- **同一天同一课程合并显示**：`groupByLesson` 聚合，显示课程编号 + 总次数
- 每行右侧有删除按钮，点击后弹出 `Modal` 二次确认，确认后删除该天该课程的**所有记录**
- `deleteRecordsByDateAndLesson` 内部已处理 `clearFirstDate` + `clearReset`

### 按周
- 显示本周内每个课程的总学习次数
- 无删除按钮
- 按课程编号从小到大排序

### 按月
- 显示本月内每个课程的总学习次数
- 无删除按钮
- 按课程编号从小到大排序

### 分页
- 按周/按月视图支持分页（日视图无需分页），每页 6 条（`PAGE_SIZE = 6`）
- 切换 Tab、切换日期范围时自动重置到第 1 页
- 分页控件居中显示，包含上一页/下一页按钮和页码按钮，当前页高亮
- 移动端页码按钮尺寸缩小（28px），间距压缩

## 汇总信息
视图底部显示小字体汇总：
```
打卡次数：X 次 | 总学习遍数：Y 遍 | 涉及课程数：Z 门
```
由 `getStats(records)` 计算：`{ checkins, total, lessons }`

## 顶部按钮组
- 标题行（header）：左侧"打卡记录"标题 + 右侧"返回打卡"按钮
- 操作栏（toolbar）：分享 / 导出 / 导入（分享触发 ShareModal multi 模式，无记录时不禁用）

## 注意事项
- 周一开始的周逻辑使用 `getWeekStart()` / `getWeekEnd()`
- Tab 切换后日期重置为今天，通过 `changeTab()` 统一处理（切换 Tab + 重置日期 + 重置页码）
- 日期导航通过 `changeDate()` 统一处理（切换日期 + 重置页码）
- 删除记录后调用 `onRefresh()` 刷新右侧复习提醒
- `dayGroups` 使用 `useMemo` 缓存，仅在 records 变化时重新计算
- 移动端：按钮间距缩小、记录项单列布局、页码按钮尺寸缩小
