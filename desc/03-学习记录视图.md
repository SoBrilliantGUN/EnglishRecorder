# 任务03：学习记录视图

## 实现位置
`app/src/components/RecordsView.jsx`

## 目标
实现按日/按周/按月三种维度查看学习记录，支持时间导航、删除记录、数据汇总。

## 视图切换
- 在打卡日历页点击"查看记录"进入记录视图
- 记录视图顶部有"返回打卡"按钮
- 三个 Tab：按日 / 按周 / 按月

## 时间导航
- 每个 Tab 下有左右箭头：
  - **按日**：前一天/后一天
  - **按周**：上一周/下一周
  - **按月**：上一月/下一月
- **不能查看未来**：右箭头最多到今天/本周/本月
- **切换 Tab 后按日视图始终回到今天**

## 数据展示规则

### 按日
- 列出当天的所有打卡记录
- **同一天同一课程合并显示**：显示课程编号 + 总次数（所有记录的 count 相加）
- 每行右侧有删除按钮，删除该天该课程的**所有记录**
- 删除逻辑：
  - 调用 `deleteRecordsByDateAndLesson(date, lesson)`
  - 若该课程所有记录被删完，调用 `clearFirstDate(lesson)` 和 `clearReset(lesson)`
  - 刷新视图和右侧复习提醒

### 按周
- 显示本周内每个课程的总学习次数（如"第1课 总计 5 次"）
- 无删除按钮
- 按课程编号从小到大排序

### 按月
- 显示本月内每个课程的总学习次数
- 无删除按钮
- 按课程编号从小到大排序

## 汇总信息
视图底部显示小字体汇总（样式简洁不突兀）：
```
打卡次数：X 次 | 总学习遍数：Y 遍 | 涉及课程数：Z 门
```
- **打卡次数**：当前时段内原始记录条目总数（未合并前）
- **总学习遍数**：所有记录的 `count` 字段总和
- **涉及课程数**：去重后的课程编号数量

## 顶部按钮组
- "返回打卡"按钮
- "分享"按钮（触发分享弹窗）
- "导出"按钮（调用 `exportData()`）
- "导入"按钮（弹出文件选择，读取 JSON 后调用 `importData()`）

## 注意事项
- 周一开始的周逻辑需使用 `getWeekStart()` 函数
- Tab 切换或打卡后需重新计算并渲染当前时段数据
- 删除记录后需刷新右侧复习提醒列表
