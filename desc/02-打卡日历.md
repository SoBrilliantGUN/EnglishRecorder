# 任务02：打卡日历

## 实现位置
`app/src/components/Calendar.jsx`

## 目标
实现月视图日历，支持选择日期、查看打卡标记。选中状态由 `App.jsx` 通过 `selected` prop 传入，点击日期通过 `onSelectDate` 回调通知父组件，不再内置打卡弹窗。

## 布局要求
- 右上角："查看记录"按钮
- 表头：一、二、三、四、五、六、日（周一开始）
- 顶部：左右箭头切换月份，中间显示"YYYY年MM月"

## 日期状态
1. **未来日期**：置灰，不可点击
2. **今天及以前**：可点击
3. **有打卡记录**：日期下方显示小圆点（`ep_records` 中 `date` 匹配）
4. **选中日期**：高亮（主题色边框/背景），由父组件 `selected` prop 控制

## 点击行为
- 点击可点击日期，调用 `onSelectDate(dateStr)` 通知父组件更新选中日期
- 打卡弹窗已移至 `DailyCard` 组件

## Props
| prop | 类型 | 说明 |
|------|------|------|
| `selected` | string | 当前选中日期（YYYY-MM-DD），由 App.jsx 传入 |
| `onSelectDate` | function | 点击日期的回调 |
| `onSwitchView` | function | 切换到记录视图 |
| `tick` | number | 变化时触发重渲染 |

## 周日处理
```javascript
function getWeekStart(date) {
  const d = new Date(date);
  const day = d.getDay(); // 0=周日
  const diff = day === 0 ? -6 : 1 - day; // 周日需要 -6
  d.setDate(d.getDate() + diff);
  return d;
}
```

## 注意事项
- 圆点标记需实时反映 `ep_records` 中的数据
- 切换月份后刷新日历，保持选中状态
