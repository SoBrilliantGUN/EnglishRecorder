# 任务05：复习提醒

## 实现位置
`app/src/components/ReviewReminder.jsx`

## 目标
实现右侧复习提醒面板，基于艾宾浩斯遗忘曲线计算每个课程的下一次复习日期。标题行右上角含 ⚙ 图标，点击在卡片底部展开/收起复习设置面板（已合并 ReviewSettings 逻辑）。

## 艾宾浩斯间隔
原始间隔天数（共7次）：`[1, 2, 4, 7, 15, 30, 60]`

实际间隔 = `Math.round(原始间隔 × 系数)`

## 计算逻辑

`getNextReview(lesson)` 动态从记录中计算，不依赖存储的 `ep_first`：

1. 取该课程所有记录，若为空返回 `null`
2. **起点**：有 `ep_resets[lesson]` 则用重置日期，否则从记录中取最早日期
3. **已完成轮次** = 起点之后有记录的不同日期数 - 1（同一天多条记录只算一次，首学不算复习）
4. `nextRound = 已完成轮次`，若 `nextRound >= 7` 返回 `null`
5. 理论复习日 = `startDate + Math.round(intervals[nextRound] × coef)`
6. **下次复习日判断**：
   - 理论日期 > 今天 → 用理论日期
   - 理论日期 ≤ 今天 且 最后一条记录日期 == 今天 → 明天
   - 理论日期 ≤ 今天 且 今天无记录 → 今天

## 显示规则
1. 遍历所有在 `ep_records` 中出现过的课程（去重）
2. 对每个课程调用 `getNextReview(lesson)`
3. 筛选出复习日期在**今天、明天、后天**之内的结果
4. 按**课程编号从小到大**排序
5. 每个课程只显示一条（最近一次复习节点）

## 每条提醒显示
```
第 X 课  第 N 次复习  YYYY-MM-DD  [重置]
```
- **重置按钮**：点击弹出二次确认框，说明重置效果（今天作为新起点，复习日期重新计算，历史记录不丢失），确认后将该课程的 `ep_resets[lesson]` 设为今天，刷新提醒列表
- 若该天是今天，日期显示为"今天"；明天显示"明天"；后天显示"后天"

## 过期提醒样式
- **判断逻辑**：理论复习日期 < 今天
- **视觉样式**：温暖琥珀光晕
  - 背景：渐变 `linear-gradient(135deg, #FFF9F0 0%, #FFF4E6 100%)`
  - 左边框：3px solid #F59E0B
  - 阴影：带琥珀色调的呼吸动画（gentleGlow）
  - 日期标签：琥珀色背景高亮
  - 重置按钮：琥珀色边框

## 空状态
若无待复习课程，显示"近3天无需复习"

## 折叠功能
- 默认显示前 3 条
- 超过 3 条时显示"展开另外 N 条"按钮
- 展开后按钮文字变为"收起"

## 设置面板（合并自 ReviewSettings）
- 标题行右侧 ⚙ 按钮，点击展开/收起，展开时图标高亮
- 展开内容位于卡片底部，以分隔线与提醒列表区分
- 间隔系数调整：-0.1 / +0.1 / 重置为 1.0，边界 0.5 ～ 3.0
- 实时预览 7 次复习日期

## 刷新时机
- 页面加载时
- 打卡成功后
- 删除记录后
- 点击重置按钮后
- 系数变更后
