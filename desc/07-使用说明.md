# 任务07：使用说明

## 实现位置
- 弹窗组件：`app/src/components/InfoModal/index.tsx`
- 原 Instructions 组件保留但不再渲染

## 触发方式
点击 Header 右侧 ⓘ 按钮，弹出使用说明弹窗

## 弹窗行为
- 使用全局 `.modal-overlay` + `.modal-content` 样式
- 点击遮罩层关闭
- 右上角 ✕ 按钮关闭

## 说明内容
```
1. 点击日历日期，右侧卡片显示该日学习内容
2. 点击右侧卡片的"打卡"按钮录入学习记录
3. 点击"查看记录"查看学习统计
4. 支持按日/周/月查看数据
5. 右侧显示近3天需复习的课程
6. 点击复习提醒右上角 ⚙ 可调整复习间隔系数（0.5~3.0）
7. 支持导出/导入数据备份
8. 可分享学习记录为图片
9. 点击顶部 ☾ 切换暗黑/亮色模式
10. 点击顶部 ⚙ 可设置是否显示复习提醒
```

## 样式
- 标题 "使用说明"，`--font-size-lg`
- 列表 `<ol>`，`line-height: 1.8`，`padding-left: 20px`
- 弹窗 `maxWidth: 420px`
