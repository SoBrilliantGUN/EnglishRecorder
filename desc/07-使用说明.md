# 任务07：使用说明

## 实现位置
- 弹窗组件：`app/src/components/InfoModal/index.tsx`
- 原 Instructions 组件保留但不再渲染

## 触发方式
点击 Header 右侧 ⓘ 按钮，弹出使用说明弹窗

## 弹窗行为
- 使用全局 `.modal-overlay` + `.modal-content` 样式
- 点击遮罩层关闭
- 右上角 ✕ 按钮关闭

## 说明内容
```
1. 点击日历日期，右侧卡片显示该日学习内容
2. 点击右侧卡片的"打卡"按钮录入学习记录（课程编号根据实际数据动态显示）
3. 日历下方为课程库，点击可查看对话文本
4. 在课程详情页点击"单课打卡"，可单独记录该课的学习次数
5. 单课打卡成功后会弹出分享卡片；若已关闭，点击"分享"按钮可再次打开
6. 点击"查看记录"查看学习统计
7. 支持按日/周/月查看数据
8. 右侧显示近3天需复习的课程
9. 点击复习提醒右上角 ⚙ 可调整复习间隔系数（0.5~3.0）
10. 支持导出/导入数据备份
11. 可分享学习记录为图片
12. 点击顶部 ☾ 切换暗黑/亮色模式
13. 点击顶部 ⚙ 可设置是否显示复习提醒
14. 推荐搭配 Saladict 沙拉查词插件：划词多词典聚合释义、自动发音、生词本、整页翻译
```

## 小屏适配
- 使用 `useScaleToFit(80)` hook，内容超过视口高度时自动等比缩小，无需滚动条
- `@media (max-height: 750px)` 先压缩间距（行高 1.8→1.6、字号 14px→13px、分割线间距 16px→10px），减少需缩放的情况
- `transform: scale()` + `transform-origin: top center` 保证内容顶部对齐不偏移

## 样式
- 标题 "使用说明"，`--font-size-lg`
- 列表 `<ol>`，`line-height: 1.8`，`padding-left: 20px`
- 弹窗 `maxWidth: 480px`
- 分隔线下方为 Saladict 推荐区块（`.tipSection`），含标题、描述文字和无序列表
