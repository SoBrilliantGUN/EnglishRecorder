# 任务00：项目结构规划

## 技术选型
- **框架**：React 19 + Vite 8 + TypeScript（strict 模式）
- **样式**：SCSS Modules + 语义化 CSS 变量 token 体系
- **外部依赖**：html2canvas（PNG 导出）、dayjs（日期处理）
- **数据存储**：localStorage

## 主题色与视觉规范
- **颜色 token 体系**：定义在 `src/styles/_variables.scss`，使用 CSS 变量（`--color-primary`、`--color-bg-card` 等）
- **主色**：`#07C160`（微信绿）
- **风格**：简洁大气，圆角卡片，柔和阴影
- **Toast 提示**：底部居中，CSS animation 控制显隐
- **按钮状态**：不可点击时置灰

## 响应式布局
- 桌面端：左右分栏（7:3，flex）
- 移动端：上下堆叠（flex-wrap）

## 开发注意事项
1. 不使用 setTimeout 等待异步操作
2. 禁止 mixins
3. 避免并发文件写操作
4. 用 `tick` prop 驱动子组件重渲染，避免在 useEffect 中直接 setState
5. 组件样式使用 SCSS Modules（`index.module.scss`），全局样式类（`.card`、`.btn-primary` 等）保留在 `index.scss`
6. TypeScript strict 模式，不允许 `any`
