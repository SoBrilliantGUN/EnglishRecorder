# 任务09：页面整体布局与样式

## 实现位置
`app/src/index.scss` + `app/src/styles/_variables.scss` + `app/src/App.tsx` + `app/src/App.module.scss`

## 目标
实现语义化 CSS 变量 token 体系、SCSS 模块化样式和响应式布局。

## 样式架构

### 颜色 token 体系（`_variables.scss`）
所有颜色、阴影、圆角、字号、动画时长统一定义为 CSS 变量：
- 主色：`--color-primary`、`--color-primary-hover`
- 背景：`--color-bg`、`--color-bg-card`、`--color-bg-elevated`、`--color-bg-muted`
- 文字：`--color-text`、`--color-text-secondary`、`--color-text-disabled`、`--color-text-inverse`
- 功能色：`--color-danger`、`--color-warning`、`--color-warning-dark` 等
- 圆角：`--radius-sm`、`--radius-base`、`--radius-lg`、`--radius-pill`
- 字号：`--font-size-xs` ~ `--font-size-xxl`
- 动画：`--transition-fast`、`--transition-base`

### 暗黑模式
- 通过 `[data-theme="dark"]` 选择器覆盖 `:root` 中的所有颜色/阴影 token
- 主题切换逻辑在 `app/src/hooks/useTheme.ts`（自定义 hook）
- 用户偏好持久化到 `localStorage` key `ep_theme`
- `index.html` 中有阻塞脚本在 CSS 加载前设置 `data-theme`，防止亮色闪烁
- Header 右侧 ☾/☀ 按钮直接切换

### 全局样式（`index.scss`）
- 通过 `@use './styles/variables'` 引入 token
- 定义全局复用类：`.card`、`.btn-primary`、`.btn-secondary`、`.modal-overlay`、`.modal-content`
  - `.modal-content`：`max-height: calc(100vh - 32px)` + `overflow: hidden`，防止弹窗内容溢出视口，配合各弹窗内部的 `useScaleToFit` 缩放实现小屏适配
- 定义全局动画：`fadeIn`、`slideUp`、`toastShow`、`gentleGlow`
- **触屏适配**：`@media (pointer: coarse)` 增大按钮最小高度（44px），取消 translateY hover 动效
- **无 hover 设备**：`@media (hover: none)` 将 hover 态改为 active 态触发

### 组件局部样式（SCSS Modules）
每个组件目录下 `index.module.scss`，类名局部作用域，避免冲突。

## React 组件结构
```
App（App.module.scss）
├── header
│   ├── 标题：EnglishPod 学习打卡
│   └── 按钮组（从左到右）：暗黑模式切换 ☾/☀ → 使用说明 ⓘ → 设置 ⚙

│   ├── .main（左侧主区域，flex: 1 1 0）

│   │   └── PodcastList / PodcastDetail（课程库，仅 calendar 视图）

│       ├── DailyCard
│       └── ReviewReminder（可通过设置隐藏）

```

## CSS 布局

### 主布局容器（`App.module.scss`）
- **`.layout`**：桌面双栏布局，`max-width: 1600px`，`display: flex; gap: 28px; flex-wrap: wrap`
- **`.layoutFull`**：全宽布局（详情页等单栏场景），不使用 flex 避免子元素不撑满
- **`.main`**：左侧主区域，`flex: 1 1 0; min-width: 0`，纵向 flex 列布局，`gap: 20px`
- **`.sidebar`**：右侧侧边栏，`flex: 0 0 350px; min-width: 0; align-self: flex-start`

### 移动端断点（`@media (max-width: 768px)`）
各组件内均有移动端样式覆盖：
- **App 布局**：padding 缩小至 12px，gap 缩小至 16px，sidebar 变为 `flex: 1 1 100%` 全宽
- **Header**：padding 和间距缩小，标题字号降级
- **Calendar**：网格间距 1px，日期格 padding 缩小，星期和导航按钮字号缩小，容器取消固定高度
- **PodcastDetail**：顶栏纵向排列（`align-items: stretch`），导航按钮换行，标题字号缩小
- **PodcastList**：网格卡片和筛选按钮缩小
- **RecordsView**：按钮间距缩小，网格单列，记录项字号缩小，容器取消固定高度
- **ReviewReminder**：系数控制行允许换行

### 触屏设备适配（`index.scss`）
- `@media (pointer: coarse)`：所有按钮最小高度 44px，`.btn-secondary` 上下 padding 加大，取消 translateY hover 动效（触屏无法触发）
- `@media (hover: none)`：hover 态改由 active 态触发，避免不支持 hover 的设备上 hover 样式滞留

## Toast
- CSS animation `toastShow` 控制显隐，无 setTimeout
- 底部居中，黑色半透明圆角

## 注意事项
- 组件中不再使用硬编码颜色值，统一引用 token 变量
- 全局共用类（按钮、卡片、弹窗）保留在 `index.scss`，组件专属样式用 SCSS Modules
- App 布局不再使用内联 style，统一使用 SCSS Modules 类名（`.layout`、`.layoutFull`、`.main`、`.sidebar`）
- 移动端断点统一为 `768px`，各组件自行处理移动端适配
- 触屏设备需同时考虑 `pointer: coarse`（增大触控区域）和 `hover: none`（hover 样式适配）
