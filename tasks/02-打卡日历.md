# 任务02：打卡日历

## 实现位置
`app/src/components/Calendar.jsx`

## 目标
实现月视图日历，支持选择日期、查看打卡标记、打卡弹窗。

## 布局要求
- 右上角："查看记录"按钮
- 表头：一、二、三、四、五、六、日（周一开始）
- 顶部：左右箭头切换月份，中间显示"YYYY年MM月"

## 日期状态
1. **未来日期**：置灰，不可点击
2. **今天及以前**：可点击
3. **有打卡记录**：日期下方显示小圆点（`ep_records` 中 `date` 匹配）
4. **选中日期**：高亮（主题色边框/背景）

## 打卡弹窗
- 点击可点击日期弹出模态框
- 输入项：
  - 课程编号（数字，必填，0-999，int）
  - 学习次数（数字，必填，默认值1，最小1）
- 确认按钮：
  - 调用 `addRecord(lesson, count, date)`
  - 若该课程首次出现，调用 `setFirstDate(lesson, date)`
  - 关闭弹窗，刷新日历圆点
  - Toast 提示"打卡成功"

## 周日处理
```javascript
function getWeekStart(date) {
  const d = new Date(date);
  const day = d.getDay(); // 0=周日
  const diff = day === 0 ? -6 : 1 - day; // 周日需要 -6
  d.setDate(d.getDate() + diff);
  return d;
}
```

## 注意事项
- 圆点标记需实时反映 `ep_records` 中的数据
- 切换月份后刷新日历，保持选中状态
- 模态框关闭时清空输入
