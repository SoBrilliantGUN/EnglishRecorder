# 任务09：页面整体布局与样式

## 实现位置
`app/src/index.css` + `app/src/App.jsx`

## 目标
实现全局 CSS 变量、响应式布局和组件样式。

## React 组件结构
```
App
├── header
├── 左侧：Calendar 或 RecordsView（view state 切换）
└── 右侧：ReviewReminder + ReviewSettings + Instructions
```

## CSS 布局
- **桌面端**：`display: flex; flex-wrap: wrap; gap: 20px`
  - 左侧：`flex: 7 1 320px`
  - 右侧：`flex: 3 1 240px`
- **移动端**：flex-wrap 自动堆叠

## 主题色应用
- 主按钮背景：`#07C160`
- 悬停状态：`#06ad52`
- 不可点击按钮：opacity 0.4

## 卡片样式
```css
.card {
  background: white;
  border-radius: 12px;
  padding: 20px;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.08);
}
```

## Toast
- CSS animation `toastShow` 控制显隐，无 setTimeout
- 底部居中，黑色半透明圆角

## 注意事项
- 移除所有 Emoji
- 圆角统一 8px~12px
