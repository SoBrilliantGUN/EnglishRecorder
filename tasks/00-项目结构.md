# 任务00：项目结构规划

## 技术选型
- **框架**：React + Vite
- **外部依赖**：html2canvas（npm 安装）
- **数据存储**：localStorage

## 文件结构
```

    ├── src/

    │   ├── index.css
    │   ├── store.js        # 数据层 + 工具函数
```

## 主题色与视觉规范
- **主题色**：`#07C160`（微信绿）
- **风格**：简洁大气，圆角卡片，柔和阴影
- **移除所有 Emoji**
- **Toast 提示**：底部居中，CSS animation 控制显隐
- **按钮状态**：不可点击时置灰

## 响应式布局
- 桌面端：左右分栏（7:3，flex）
- 移动端：上下堆叠（flex-wrap）

## 开发注意事项
1. 不使用 setTimeout 等待异步操作
2. 禁止 mixins
3. 避免并发文件写操作
4. 用 `tick` prop 驱动子组件重渲染，避免在 useEffect 中直接 setState
