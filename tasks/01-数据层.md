# 任务01：数据层

## 实现位置
`app/src/store.js`

## 目标
封装所有 localStorage 读写操作，提供统一的数据访问接口和工具函数。

## 初始化逻辑
- 页面加载时检查 `ep_initialized` 标志
- 若不存在，插入2条示例记录（当天日期，课程1听了1次，课程2听了2次），并设置 `ep_initialized = true`
- 同时初始化 `ep_first`：课程1和课程2的首次学习日期均为今天

## 数据读写接口

### 记录相关
```javascript
getRecords()                          // 获取全部记录，返回数组
saveRecords(records)                  // 保存全部记录
addRecord(lesson, count, date)        // 新增一条记录
deleteRecordsByDateAndLesson(date, lesson)  // 删除某天某课程的所有记录
```

### 课程首次学习日期
```javascript
getFirstDates()                       // 返回 ep_first 对象
setFirstDate(lesson, date)            // 设置某课程首次学习日期（仅在该课程首次出现时调用）
clearFirstDate(lesson)                // 删除某课程的首次学习日期
```

### 重置状态
```javascript
getResets()                           // 返回 ep_resets 对象
setReset(lesson, date)                // 重置某课程的复习起点为指定日期
clearReset(lesson)                    // 清除某课程的重置状态
```

### 系数
```javascript
getCoef()                             // 返回系数，默认1.0
setCoef(value)                        // 保存系数（范围 0.5~3.0，写入前 clamp）
```

### 导入导出
```javascript
exportData()           // 返回包含所有4个key的JSON对象，触发下载文件名：englishpod-backup-YYYY-MM-DD.json
importData(jsonObj)    // 完整替换所有 localStorage 数据（ep_records/ep_coef/ep_first/ep_resets）
```

## 记录ID生成规则
```javascript
id = `${Date.now()}-${Math.random().toString(36).slice(2, 7)}`
```

## 注意事项
- 课程编号统一存为数字类型（parseInt）
- 所有日期格式统一为 `YYYY-MM-DD`
- 若某课程所有记录被删除，需同时调用 `clearFirstDate` 和 `clearReset`
