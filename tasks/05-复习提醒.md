# 任务05：复习提醒

## 实现位置
`app/src/components/ReviewReminder.jsx`

## 目标
实现右侧复习提醒面板，基于艾宾浩斯遗忘曲线计算每个课程的下一次复习日期。

## 艾宾浩斯间隔
原始间隔天数（共7次）：`[1, 2, 4, 7, 15, 30, 60]`

实际间隔 = `Math.round(原始间隔 × 系数)`

## 计算逻辑
```javascript
function getNextReview(lesson) {
  const firstDates = getFirstDates();
  const resets = getResets();
  const coef = getCoef();
  const intervals = [1, 2, 4, 7, 15, 30, 60];

  // 起点：有重置记录用重置日期，否则用首次学习日期
  const startDateStr = resets[lesson] || firstDates[lesson];
  if (!startDateStr) return null;

  const startDate = new Date(startDateStr);
  const today = new Date(todayStr()); // YYYY-MM-DD

  for (let i = 0; i < intervals.length; i++) {
    const days = Math.round(intervals[i] * coef);
    const reviewDate = addDays(startDate, days);
    if (reviewDate >= today) {
      return { lesson, round: i + 1, date: formatDate(reviewDate) };
    }
  }
  return null; // 7次复习全部完成
}
```

## 显示规则
1. 遍历所有在 `ep_first` 中有记录的课程
2. 对每个课程调用 `getNextReview(lesson)`
3. 筛选出复习日期在**今天、明天、后天**之内的结果
4. 按**课程编号从小到大**排序
5. 每个课程只显示一条（最近一次复习节点）

## 每条提醒显示
```
第 X 课  第 N 次复习  YYYY-MM-DD  [重置]
```
- **重置按钮**：将该课程的 `ep_resets[lesson]` 设为今天，刷新提醒列表
- 若该天是今天，日期显示为"今天"；明天显示"明天"；后天显示"后天"

## 空状态
若无待复习课程，显示"近3天无需复习"

## 折叠功能
- 默认显示前 3 条
- 超过 3 条时显示"展开另外 N 条"按钮
- 展开后按钮文字变为"收起"

## 刷新时机
- 页面加载时
- 打卡成功后
- 删除记录后
- 点击重置按钮后
- 系数变更后
